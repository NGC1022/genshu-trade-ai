# 需求文档

## 1. 应用概述

### 1.1 应用名称
根生万象（AI非遗文创跨境贸易助手）

### 1.2 应用描述
根生万象是一款基于微信小程序的非遗文创综合服务与AI跨境贸易业务自动化助手。平台在保留消费者端商城、文旅门票、定制服务与社区互动功能的基础上，深度赋能AI跨境贸易中台与商家运营业务端。本期重点针对订单确认页结算明细进行多币种实时汇率技能集成与降级展示优化，并对全站移动端版面布局实施标准化排版与可读性优化，确保非遗文创跨境交易体验的严谨性与易用性。

---

## 2. 用户角色与使用场景

### 2.1 目标用户与角色
1. 普通消费者：浏览购买文创商品、在订单确认页查看多币种实时换算结算明细、查询物流清关轨迹及申请售后。
2. 商家运营人员：管理商品SKU与库存、跟进海外客户CRM、处理询盘意向、制定并生成商务报价、生成贸易单证草稿及处理订单异常。
3. 审核人员：对AI生成的合规建议、报价草稿、贸易单证、营销素材及出海方案进行人工核对与确认。
4. 系统管理员：维护系统配置（含支持结算币种与演示汇率底表）、监控数据看板及演示数据重置。

### 2.2 核心使用场景
1. 跨境订单多币种结算：消费者在订单确认页提交订单前，系统调用实时汇率技能换算并展示多币种金额；接口异常时自动降级至演示汇率并显式标注，确保结算金额精确可读。
2. 移动端高效浏览与操作：用户在手机端浏览商品详情、订单结算明细、AI贸易工作台及商家后台时，界面布局符合移动端排版规范，文字不贴边、间距合理、点击热区充足且无横向溢出。

### 3.2 消费者端核心功能说明

#### 3.2.1 订单确认页（order-confirm）与实时汇率换算
1. 基础信息展示：展示收货地址选择卡片、购买商品明细（SKU、单价、数量）、配送物流选项及优惠抵扣信息。
2. 实时汇率查询与触发时机：
  - 进入订单确认页加载结算数据时，自动触发实时汇率查询技能。
  - 切换目的国/收货地址或选择不同目标币种时，重新触发汇率换算。
3. 多币种结算明细展示：
  - 主金额展示：保留本币（CNY）标准结算金额（商品金额、运费、预估关税、应付总额）。
  - 换算金额展示：基于后台配置支持的币种（如USD、EUR、JPY、SGD、KRW），在结算明细区展示换算后金额，格式化为带标准币种符号及两位小数（JPY/KRW按整数规范处理），严禁出现undefined、null或NaN。
4. 汇率模式与状态标识：
  - 实时汇率模式：接口调用成功时，展示当前汇率数值及「更新时间：YYYY-MM-DD HH:mm」，提供轻量刷新按钮。
  - 演示汇率降级模式：当接口调用失败、超时或离线时，系统自动无缝降级读取后台演示汇率底表，并显式标注「演示汇率数据（非实时），仅供参考」。

#### 3.2.2 基础商城与定制服务
1. 商品浏览与选购：展示平价文创、高端文创及IP周边，支持多规格SKU选择、价格与库存展示。
2. 定制服务：支持1-4字根书印章定制及4种IP模版的3D打印定制，实时生成预览并支持提交订单。
3. 国际化收货地址：根据所选国家/地区自动适配地址字段与国际区号电话格式。

#### 3.2.3 订单全生命周期、物流追踪与售后
1. 全生命周期节点展示：按照「待付款→已付款→备货中→已发货→国际运输中→目的国清关→清关完成→末端配送→已签收→售后期→订单完成」展示完整时间轴与操作备注。
2. 国际物流轨迹与清关状态：展示分段物流节点详情，独立展示待清关、清关中、清关完成、清关异常四类状态进度。
3. 独立售后中心：支持退货、换货、仅退款及物流破损申报，支持凭证上传与状态同步追踪。

#### 3.2.4 多语言客服与文旅社区
1. 多语言客服：保留原文，支持中英双语实时互译，提供原文与翻译对照展示。
2. 文旅门票与社区：门票购买与二维码核销；社区笔记发布、草稿保存、多级评论及用户追踪标识。

### 3.3 商家业务端核心功能说明

#### 3.3.1 AI贸易合规助手与单证中心
1. AI合规报告：支持商品合规审查、HS编码建议、目的国进口要求与风险清单输出，显式标注免责声明。
2. 单证草稿生成：基于已确认订单生成PI、CI、装箱单、订单确认单及装运指示草稿，缺失数据统一标记为「待填写」。

#### 3.3.2 海外客户CRM与智能报价工作台
1. 客户档案与意向识别：汇聚询盘信息，提取采购意图并沉淀至客户档案。
2. 确定性计算报价：商品总金额与总成本由程序严密计算，AI生成英文商务报价说明，支持版本管理与人工确认。

#### 3.3.3 商品库存、营销素材与异常订单
1. SKU库存与国际化资料：维护多规格库存并校验供货能力，检查国际化资料完整度。
2. AI营销素材库：生成英文标题、卖点提炼、社媒文案与脚本，支持人工审核归档。
3. 异常订单中心：归类物流与清关异常，生成AI处理建议与英文通知草稿。

### 3.4 移动端版面排版与视觉规范（增量优化）

本轮优化保持现有红色主色调（#C92A2A）与整体设计风格不变，对核心页面（订单确认页、商品详情页、AI贸易助手各模块、商家后台）实施版面标准化细修：

1. 卡片与容器内边距规范：
  - 页面外层统一留白：左右外边距固定为12px-16px。
  - 内容卡片内边距：通用卡片内边距统一设置为12px-16px，严格杜绝文字、图标紧贴卡片边框或分割线的现象。
2. 字号与行高层级梯度：
  - 模块标题/核心金额：18px-20px，加粗，行高1.3-1.4。
  - 卡片子标题/主要字段名：15px-16px，中粗，行高1.4。
  - 核心正文/输入框文本/列表内容：13px-14px，常规字重，行高1.5。
  - 辅助说明/汇率更新时间/降级标签/免责提示：11px-12px，弱化字色，行高1.4。
3. 元素间距与按钮防挤压：
  - 文本段落与操作按钮之间必须保留至少12px-16px的垂直间距，禁止文字与按钮紧贴。
  - 表单输入区域纵向间距统一为10px-14px，防止输入项堆叠。
  - 底部操作栏/吸底结算栏上方留足安全区及占位高度，避免内容被遮挡。
4. 触控热区与防溢出：
  - 移动端按钮最小点击高度不低于40px（核心提交/支付按钮为44px-48px），确保单手触控准确。
  - 所有表格、表单输入框、单证预览文本均配置自动换行与弹性伸缩样式，严禁出现横向非预期滚动或内容截断溢出屏幕。

## 4. 业务规则与核心逻辑

1. 汇率换算与展示规则：订单确认页主支付金额严格以本币（CNY）确定性计算为准；多币种换算作为辅助展示，换算公式为「目标币种金额 = 本币金额 × 对应汇率」。
2. 汇率降级与容错规则：当实时汇率接口请求超时（>3秒）、网络断开或返回异常时，系统静默降级为后台内置演示汇率，且界面必须附带「演示汇率数据」显式标识，不得阻塞用户下单结算主流程。
3. 金额数据格式化强校验：所有前端展示金额必须经过格式化工具统一处理，数值异常时兜底显示为「--」或「0.00」，严禁暴露NaN或undefined。
4. AI与业务数据审核边界：涉及价格、税费、合规审查及正式单证的AI生成内容，默认状态为「待人工审核」，未经人工确认不得作为正式业务凭证。
5. 演示数据隔离与重置规则：演示数据重置仅对演示标识记录生效，不影响真实业务数据与基础系统配置。

## 5. 异常与边界情况

| 业务场景 | 异常情况 | 系统处理逻辑 |
|----------|----------|--------------|
| 订单确认页汇率查询 | 实时汇率查询接口超时或返回失败 | 自动降级使用本地/后台演示汇率进行换算，并在汇率栏显示「演示数据」标签，不中断下单 |
| 多币种金额计算 | 汇率参数异常或返回非数字字符 | 金额格式化函数拦截异常，输出兜底值「--」，记录前端警告日志，禁止渲染NaN |
| 移动端小屏设备浏览 | 商品标题或单证长字段文本过长 | 文本自动折行或按CSS规则展示省略号，外层容器保持固定边距，禁止横向撑破卡片 |
| 订单结算快速点击 | 用户连续快速点击提交订单按钮 | 按钮触发后立即进入加载禁用态，防重复提交，直至当前请求响应完毕 |
| 国际电话输入 | 手机号与当前选择国家区号规则不符 | 表单标红提示「请输入符合该国家格式的联系电话」，阻断提交 |

## 6. 验收标准

1. 实时汇率换算展示验收：进入订单确认页，系统成功调用汇率服务并展示对应外币金额与汇率更新时间；金额格式准确且无NaN/undefined。
2. 汇率服务降级验收：断网或模拟接口异常时，订单确认页自动切换至演示汇率换算，界面明确标注「演示数据」，且下单流程仍可正常完成。
3. 版面内边距与排版验收：检查商品详情页、订单确认页、AI贸易助手及商家后台，卡片文字与边框间距≥12px，文字与操作按钮间距≥12px，无文字贴边与挤压现象。
4. 字号层级与可读性验收：标题、正文、辅助提示字号梯度分明（20px/16px/14px/12px），在移动端小屏设备上清晰易读。
5. 防溢出与触控验收：各页面表单与长文本在各类屏幕宽度下均无横向溢出，按钮点击热区高度≥40px。
6. 现有业务闭环兼容验收：B2B/RFQ订单流转、CRM管理、单证生成、售后中心及演示数据重置等既有功能均保持正常运行。
